# 命令行接口

本文说明当前可运行的查询与比较命令、选项和退出码。JSON 报告选项仍属于文末的[后续接口](#后续接口)，当前程序尚不接受这些选项。

## 命令

```text
dnslab query <名称> --server <IP端点> [选项]
dnslab query <名称> --doh <HTTPS地址> [选项]
dnslab query <名称> --dot <主机或IP端点> [选项]
dnslab compare <名称> --server <IP端点> --server <IP端点> [选项]
```

`query` 接受恰好一个查询名称，且必须从 `--server`、`--doh`、`--dot` 中恰好选择一项。查询名称是域名或根名，不是 URL。

`compare` 接受恰好一个查询名称与至少两个不同的普通 IP 端点；通过重复 `--server` / `-s` 指定，每次选项只带一个地址。规范化后重复的端点属于参数错误，不静默去重。全部输入校验通过后才开始联网。

普通服务器使用 IP 端点；DoH 使用 HTTPS 地址；DoT 使用主机名或 IP 端点。名称、地址、端口和 CA 文件的完整规则见[输入校验](validation.md)。

## 选项

`--server`、`--type`、`--transport`、`--timeout-ms` 用于查询与比较；加密相关选项仅用于 `query`。

| 长选项 | 短选项 | 约定 |
| --- | --- | --- |
| `--server <IP端点>` | `-s` | 普通 DNS 服务器；`query` 只接受一个，`compare` 可重复指定不同端点 |
| `--doh <HTTPS地址>` | 无 | DoH 服务器；不能与 `--transport` 同用 |
| `--dot <主机或IP端点>` | 无 | DoT 服务器；不能与 `--transport` 同用 |
| `--ca-file <路径>` | 无 | 仅用于 DoH/DoT，指定 PEM CA 文件；仍验证证书链与服务器身份 |
| `--type A\|AAAA\|CNAME\|MX\|TXT\|NS\|SOA\|PTR` | `-t` | 默认 `A`；类型值大小写不敏感，查询与比较使用同一支持范围 |
| `--transport auto\|udp\|tcp` | `-T` | 仅配合 `--server`，默认 `auto`；值区分大小写 |
| `--timeout-ms <毫秒数>` | 无 | 每台服务器的查询总预算，默认 1500 ms；整数范围 100–30000，含边界 |
| `--help` | `-h` | 显示当前命令帮助并成功退出 |
| `--version` | `-V` | 仅在顶层显示版本并成功退出 |

选项名称区分大小写：`-t` 是记录类型，`-T` 是传输方式。除 `compare` 的 `--server` 外，带值选项均为单值，重复相同值或混用长短形式重复指定都会报错。未知选项、缺值、名称缺失或多余、无效值和无效组合均属于参数错误。`compare` 不接受 `--doh`、`--dot` 或 `--ca-file`。

参数形式、查询名称、端点与 CA 文件的基本检查在网络请求前完成。TLS 后端继续解析证书内容并验证信任关系：CA 文件预检失败或后端报告 CA 文件无法加载时，返回参数错误 `2`；服务器证书的信任链、有效期或身份验证失败时，返回查询失败 `1`。加密查询显式指定 `--transport auto` 也属于参数错误。

所有查询使用 `IN` 类别。`ANY`、`AXFR`、未列出的类型、裸数字及 `TYPE数字` 形式均不接受。名称仍遵守[输入校验](validation.md#查询名称)，新增类型不放宽字符规则。PTR 可直接查询反向名称，例如 `query 1.2.0.192.in-addr.arpa -s 1.1.1.1 -t PTR`；程序不自动反转 IP，也不自动追踪 CNAME 目标。

## 传输与超时

- `udp`：只执行 UDP 查询，保留有效响应中的 TC 截断标志。
- `tcp`：直接通过 TCP 查询。
- `auto`：先 UDP，仅在完整且匹配请求的响应带 TC 时，向同一服务器发送同一查询进行一次 TCP 回退；UDP 超时不回退，TCP 响应仍带 TC 时不继续重试。
- `--doh`：发送 HTTPS POST，正文为 DNS 报文，不跟随重定向。
- `--dot`：建立 TLS 连接，收发带两字节长度前缀的 DNS 报文。

整个查询共用一个超时预算，覆盖 UDP 收发、TCP 连接与收发、UDP→TCP 回退，以及加密服务器名称解析、TLS 握手和消息交换。回退只使用剩余时间；部分收发和不匹配响应不会重置预算。

DoH/DoT 严格验证证书链、有效期与主机名或 IP，最低 TLS 1.2；失败不切换明文，也不提供跳过验证选项。Windows 默认使用系统信任库，Linux 使用运行环境的 CA 文件；私有 CA 可通过 `--ca-file` 指定。

Windows 的同步证书检索可能使实际返回晚于超时预算；返回后仍判定是否超时，具体边界见[加密传输](network.md#doh-与-dot)。

加密查询不使用代理环境变量。服务器为主机名时，需要先解析该服务器名称，这一步可能使用本机配置的普通 DNS。

## 服务器比较

`compare` 按输入顺序逐台调用普通查询，每台使用相同的记录类型、传输模式和预算。每个端点执行一次查询，可在其内部按 `auto` 规则回退；一台失败后继续下一台，下一台重新取得完整预算。整个比较的耗时可以超过单台预算。

输出保留每台服务器的完整响应或失败原因、实际传输、耗时和尝试过程。差异摘要以首个成功响应为参照，分别比较响应码、标志、回答、权威记录、附加记录和 TTL；事务 ID、记录顺序及名称的 ASCII 大小写不影响一致性，重复记录和未知记录数据仍参与比较。TTL 只比较相同身份的记录，无法配对的记录归入所在记录区的内容差异。

名称比较也适用于 NS/CNAME/PTR 目标、MX 交换机和 SOA 的两个名称，压缩方式不影响结果。MX 优先级与 SOA 数值字段精确比较；TXT 按原始字节及分段边界比较，区分大小写，`"ab" "c"` 与 `"a" "bc"` 不相同。

失败项不视为空答案；不足两个成功响应时明确提示无法比较。有效 DNS 错误响应码仍可参与比较，不据此评判服务器好坏，也不根据单次耗时排名。

## 帮助与版本

不带参数运行时显示顶层帮助并成功退出。`dnslab --help`、`dnslab query --help` 与 `dnslab compare --help` 显示各自范围的帮助，不要求名称或服务器，也不发起网络请求。`-h` 与 `--help` 等价。不提供 `-q`、`-c` 子命令别名。

`dnslab --version` 与 `dnslab -V` 输出当前版本 `DNSLab 0.1.0`。子命令下使用 `--version` 是参数错误。

帮助、结果与错误说明使用中文；命令、选项、协议缩写、记录类型和 DNS 响应码保留原标识。重定向输出采用 UTF-8，Windows 支持包含中文的参数路径。

## 输出与退出码

标准输出展示目标、实际传输、耗时、响应码、事务 ID、TC 标志、问题、回答、权威记录、附加记录及各次尝试。记录保留名称、TTL、类别和类型；未知记录的数据以长度和十六进制字节展示。

NS、CNAME、PTR 显示带尾点的目标名称。MX 显示优先级和交换机名称；SOA 依次显示主服务器、责任人名称、序列号、刷新间隔、重试间隔、过期时间和最小 TTL。TXT 每段分别放入双引号并用空格分隔，保留空段；双引号、反斜杠、控制字节和非 ASCII 字节统一转义为三位十进制 `\DDD`，例如 `\034`、`\092`、`\010`，不直接输出控制字符。

NOERROR 但没有与原问题名称、类型和类别匹配的直接答案时，会明确提示缺少直接答案，不宣告名称不存在。CNAME 目标上的地址和附加记录不会被当作原问题的直接答案。

失败时保留已有尝试记录，并向标准错误输出中文原因；可用的系统错误码、后端错误码、HTTP 状态或报文字节偏移一并保留。有效 UDP 截断响应后的 TCP 回退失败，整体仍按查询失败返回。

| 退出码 | 含义 |
| ---: | --- |
| `0` | 收到可解析且匹配请求的 DNS 响应，或成功显示帮助、版本 |
| `1` | 查询超时、网络或证书验证失败、响应无效 |
| `2` | 命令行参数或输入无效 |
| `3` | 内部错误，例如事务 ID 生成失败、加密后端能力不足或输出异常 |

有效的 NXDOMAIN、SERVFAIL、REFUSED 等响应仍返回 `0`，不会因非零 DNS 响应码单独判定查询失败。

比较中的全部服务器获得有效 DNS 响应时返回 `0`，即使答案不同；任一查询失败返回 `1`，其他结果仍保留。参数错误返回 `2` 且不联网；内部错误优先返回 `3`。

## 示例

```text
dnslab query example.com -s 1.1.1.1 -t A
dnslab query example.com -s "[2606:4700:4700::1111]:53" -t AAAA
dnslab query example.com -s 1.1.1.1 -T tcp --timeout-ms 3000
dnslab query example.com --doh https://cloudflare-dns.com/dns-query
dnslab query example.com --dot dns.google -t AAAA
dnslab compare example.com -s 1.1.1.1 -s 8.8.8.8 -t AAAA
dnslab compare example.com -s 1.1.1.1 -s 8.8.8.8 -T tcp --timeout-ms 3000
```

使用自建服务器及私有 CA 时，将服务器和文件路径替换为实际值：

```text
dnslab query example.com --dot resolver.example:8853 --ca-file private-ca.pem
```

## 后续接口

本节保留已经确认、尚未提供的报告接口；当前程序调用这些选项会返回参数错误。

### 报告选项

| 选项 | 约定 |
| --- | --- |
| `--output <路径>` / `-o` | 查询或比较结束后写入完整 JSON 报告，同时保留终端结果；为单值选项，重复指定报错 |
| `--force` / `-f` | 仅与 `--output` 配合使用，明确允许覆盖已有报告文件 |

默认拒绝覆盖已有文件；单独使用 `--force` 是参数错误，返回 `2`。报告写入失败返回 `3`，不能宣称保存成功；如果同时发生查询失败，最终仍返回 `3`。
