Windows 标签运行的最大 DoH 报文案例未能及时结束。原测试服务在 TLS 接管套接字后仍尝试关闭失效的旧句柄，已通过沉默客户端确定性复现清理失败；清理异常还可能覆盖客户端原始结果。现已改为工作线程内可取消的非阻塞操作，并补充阶段及客户端诊断。

最大报文原始超时未在本机重现，不能仅凭清理缺陷认定其全部原因；容量案例改用独立预算，超时专用案例保持原值。运行环境和构建策略见[持续集成](build.md#持续集成)。

本次 37 项加密测试在原始 MSVC 产物与本机程序上分别全部通过，其中包含新增的四项服务生命周期与诊断回归。受限执行环境不能完成 Schannel 握手，不能用该环境的握手失败判定本次查询回归。已有产物测试入口也能发现全部 276 项，包含 12 项比较命令行案例。

本机五项 IPv6 回环失败已定位到 v2rayN / sing-box 的 TUN 规则：自动路由、严格路由开启，但未配置 TUN IPv6 地址，生成的 `block ipv6` 过滤器阻断了 `::1`。独立 Python 的 UDP/TCP 探针均命中同一过滤器；地址、路由和 Windows 防火墙并非阻断来源。配置尚未修改，测试未跳过，排查方式见[本机网络测试失败](build.md#本机网络测试失败)。

当前测试覆盖报文长度与压缩边界、来源及响应匹配、部分收发、回退预算、错误历史，以及加密连接的证书失败、HTTP 状态和类型、消息长度、主机名、代理隔离与中文路径。测试均使用本地服务器；证书和撤销检查说明见 [TLS 测试夹具](../tests/fixtures/tls/README.md)。
