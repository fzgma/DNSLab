当前测试包含 119 个单元用例、75 个系统与本地网络集成用例，以及 1 个覆盖多种调用的命令行冒烟测试，全部离线。本机单元与冒烟全部通过，集成 70/75 通过；测试分类、逐案例发现和产物迁移入口均已验证。[Actions 第 2 次运行](https://github.com/fzgma/DNSLab/actions/runs/38730605290)对应 `6f37a19`，四个平台全部通过，Linux 三个发行版复用同一份产物并核对哈希。

- 名称测试覆盖长度边界、截断、极大偏移、异常字节、纯数字输入、压缩循环、最大指针目标和长合法引用链。
- 报文测试覆盖查询黄金字节、标志位隔离、四个集合、A/AAAA/CNAME、未知记录、每处截断、计数与长度错误、65535 字节边界和尾随数据。
- 网络基础测试覆盖端点规范化、重复与输入错误、IPv4/IPv6 套接字类型、移动与释放、本机非阻塞行为，以及固定时刻下的共享预算、取整和极值。
- UDP 测试覆盖空数据报、大数据报、真实来源、响应匹配、无响应、错误响应后恢复和持续无关响应不续期。IPv4 的 A、AAAA、CNAME 回答已通过。
- TCP 与回退测试覆盖 12/65535 字节帧、分段前缀与正文、连续多帧、发送背压、无效帧后恢复、提前关闭、连接拒绝、同报文回退、失败历史和两次传输共享预算。
- 本机失败项为 IPv6 UDP/TCP 往返、两种查询与自动回退。独立 Python 和原生 Winsock 程序也收不到 `::1` UDP 数据，TCP 则返回系统错误 10013；受限环境内外结果相同，具体系统原因尚未确定。没有跳过这些用例或修改系统设置，跨平台结果由 Actions 单独验证。
- Windows 本机约 2.1 秒才报告连接拒绝，拒绝分类用例使用 5 秒预算等待原生错误；专门的短预算用例保留原时限。背压用例先用有界小块发送确认缓冲区持续不可写，再验证 80 毫秒预算。
