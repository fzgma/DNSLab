# 首版范围与验收

完整 MVP 的交付目标是查询指定 DNS 服务器、展示结果、比较多个普通服务器并保存 JSON 报告。本文定义交付要求和验收标准，不表示这些能力当前均已提供。

当前支持范围与操作方式见[项目首页](../README.md)和 [CLI](cli.md)，尚未完成的任务见[待办](todo.md)。

## 交付范围

| 范围 | 要求 |
| --- | --- |
| 查询 | 支持 [CLI](cli.md#选项) 列出的记录类型；普通服务器使用显式 IPv4/IPv6 端点，加密服务器也可使用主机名 |
| 传输 | UDP、TCP、有效截断响应后的 TCP 回退、DoH、DoT |
| 展示 | 中文帮助与诊断；响应码、记录、TTL、目标、传输、耗时和尝试过程 |
| 输入与错误 | 网络前检查无效输入；区分参数、查询和内部错误 |
| 比较 | 对多个不同普通 DNS 端点各查询一次，保留独立结果并展示差异 |
| 报告 | 带版本信息的 JSON 报告、Schema、覆盖保护及写入失败处理 |
| 质量保障 | 离线测试、Windows/Linux 构建与测试流程、使用文档 |

目标平台为 Windows 10/11 x64 和 Linux x86_64；持续集成覆盖 Windows 托管环境、Ubuntu 与 Debian 最新稳定版、Arch 滚动版。

## 验收标准

发布候选版本须满足以下条件：

- 命令行测试覆盖 `query`、`compare`、中文帮助与输出、UTF-8 参数路径、输入校验和退出码。
- 普通传输测试覆盖 UDP、显式 TCP、有效 TC 响应后的单次回退、部分收发和无效响应；UDP 超时不回退，各阶段不重置查询预算。
- 加密传输测试覆盖 DoH/DoT 正常查询、严格证书验证和异常响应；预算行为符合[网络约定](network.md#doh-与-dot)，失败不降级为明文。
- 比较测试覆盖重复端点预检、独立预算、局部失败保留及响应差异展示。
- 协议测试覆盖全部支持类型、MX 与 SOA 字段、TXT 分段与安全显示、空回答、DNS 错误响应码、无直接答案、长度与计数错误、压缩循环及指针越界。
- 报告通过 JSON Schema 校验，保留失败项，并验证文件覆盖保护和写入失败处理。
- 单元测试使用内存数据，集成测试使用本地模拟服务器，不依赖公共 DNS；目标 Windows/Linux 环境均运行完整测试，包含 IPv4/IPv6 和真实命令路径。
- 使用文档、示例与发布交付物准确反映最终支持范围；不同版本或局部测试的结果不能替代发布候选版本的完整验收。

## 响应与输出交付

### 终端结果

每次查询展示问题、实际目标、传输、耗时、响应码和尝试记录。有回答时展示名称、类型、类别、TTL 与值，并保留回答、权威记录和附加记录的归属。

- 有效的 NXDOMAIN、SERVFAIL、REFUSED 等响应属于传输成功。
- 常见响应码显示标准名称，未知响应码保留数值。
- NOERROR 但没有目标类型的直接答案时明确提示，不宣告名称不存在。
- 自动回退保留 UDP 截断响应与 TCP 最终结果，回退失败不能被当作整体成功。
- 不支持解码的记录保留类型编号、RDATA 长度与原始字节。
- 比较展示每台服务器的结果和差异，不直接判定哪个答案正确或哪个服务器最好。

### JSON 报告

报告应包含本次所有服务器的结果，包括失败项。

| 顶层字段 | 内容 |
| --- | --- |
| `schema_version`、`tool_version` | 报告结构版本与程序版本 |
| `started_at`、`duration_ms` | 含时区的 RFC 3339 开始时间、总耗时 |
| `query` | 查询名称与类型 |
| `options` | 本次使用的超时和传输选项 |
| `results` | 每个服务器一项的完整结果 |

每项结果最少包含 `server`、`transport_used`、`elapsed_ms`、`transport_status`、`rcode`、`flags`、`answers` 和 `error`。未收到有效响应时，`rcode` 与有效响应耗时 `elapsed_ms` 为 `null`；没有错误时 `error` 为 `null`。

`transport_status` 使用稳定枚举，区分成功、超时、连接拒绝、收发失败和无效响应。`flags` 至少保留 `tc`、`aa`、`ra`、`ad`、`cd`；答案保留名称、类型、TTL 与值。UDP 截断和 TCP 回退过程必须可追溯。

报告实现时提交 JSON Schema 和对应测试。发布后的字段与含义保持兼容；破坏性调整提高 `schema_version`。比较命令见 [CLI](cli.md#服务器比较)，报告选项见 [CLI 后续接口](cli.md#后续接口)。

## 协议与实现约束

DNS 报文构造与解析由项目自行实现，不能用现成 DNS 客户端库替代协议核心。响应须经过完整解析和事务匹配，UDP 还须验证来源；普通与加密传输均遵守同一查询总预算，证书验证失败不得回退明文。

名称与报文边界见[编解码约定](wire-codec.md)，传输细节见[网络约定](network.md)，职责与依赖见[架构](architecture.md)。输入规则集中在[输入校验](validation.md)，当前命令默认值和退出码集中在 [CLI](cli.md)。

## 不属于首版

- ANY、AXFR、任意类型编号和支持列表以外的直接查询类型。
- 多轮采样、延迟百分位、排名、历史数据库和实时监控。
- DNSSEC 验证、IDN 自动转换、加密服务器比较、自动发现和代理配置。
- 自动递归追踪 CNAME、权威服务器发现或根服务器迭代查询。
- CSV、Markdown 报告和图形界面。

长期候选见[产品需求](prd.md)。

## 交付物

- 源码、依赖声明和可复现的构建步骤。
- 经目标平台验证的程序与离线测试流程。
- 中文命令帮助、使用文档、报告 Schema 与示例。
- 准确的支持范围和限制。
