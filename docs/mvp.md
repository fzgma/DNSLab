# 首版范围与验收

v0.1.0 的交付目标是查询指定 DNS 服务器、展示结果、比较多个普通服务器并保存 JSON 报告。单服务器查询已开发完成；比较和报告尚未实现，首版仍处于开发阶段。

当前操作方式见 [CLI](cli.md)，具体测试环境与结果只记录在[验证状态](todo.md#验证状态)。

## 交付范围

| 范围 | 要求 | 开发状态 |
| --- | --- | --- |
| 查询 | A、AAAA；普通服务器使用显式 IPv4/IPv6 端点，加密服务器也可使用主机名 | 已实现 |
| 传输 | UDP、TCP、有效截断响应后的 TCP 回退、DoH、DoT | 已实现 |
| 展示 | 中文帮助与诊断；响应码、记录、TTL、目标、传输、耗时和尝试过程 | 已实现 |
| 输入与错误 | 网络前检查无效输入；区分参数、查询和内部错误 | 已实现 |
| 比较 | 对多个不同普通 DNS 端点各查询一次，保留独立结果并展示差异 | 待实现 |
| 报告 | 带版本信息的 JSON 报告、Schema、覆盖保护及写入失败处理 | 待实现 |
| 质量保障 | 离线测试、Windows/Linux 构建与测试流程、使用文档 | 已建立；平台结果见验证状态 |

目标平台为 Windows 10/11 x64 和 Linux x86_64；持续集成覆盖 Windows 托管环境、Ubuntu 与 Debian 最新稳定版、Arch 滚动版。已有阶段的跨平台通过记录不替代当前版本的验收。

## 响应与输出交付

### 终端结果

每次查询展示问题、实际目标、传输、耗时、响应码和尝试记录。有回答时展示名称、类型、类别、TTL 与值，并保留回答、权威记录和附加记录的归属。

- 有效的 NXDOMAIN、SERVFAIL、REFUSED 等响应属于传输成功。
- 常见响应码显示标准名称，未知响应码保留数值。
- NOERROR 但没有目标类型的直接答案时明确提示，不宣告名称不存在。
- 自动回退保留 UDP 截断响应与 TCP 最终结果，回退失败不能被当作整体成功。
- 不支持解码的记录保留类型编号、RDATA 长度与原始字节。
- 后续比较展示每台服务器的结果和差异，不直接判定哪个答案正确或哪个服务器最好。

### JSON 报告

以下为待实现的交付要求。报告包含本次所有服务器的结果，包括失败项。

| 顶层字段 | 内容 |
| --- | --- |
| `schema_version`、`tool_version` | 报告结构版本与程序版本 |
| `started_at`、`duration_ms` | 含时区的 RFC 3339 开始时间、总耗时 |
| `query` | 查询名称与类型 |
| `options` | 本次使用的超时和传输选项 |
| `results` | 每个服务器一项的完整结果 |

每项结果最少包含 `server`、`transport_used`、`elapsed_ms`、`transport_status`、`rcode`、`flags`、`answers` 和 `error`。未收到有效响应时，`rcode` 与有效响应耗时 `elapsed_ms` 为 `null`；没有错误时 `error` 为 `null`。

`transport_status` 使用稳定枚举，区分成功、超时、连接拒绝、收发失败和无效响应。`flags` 至少保留 `tc`、`aa`、`ra`、`ad`、`cd`；答案保留名称、类型、TTL 与值。UDP 截断和 TCP 回退过程必须可追溯。

报告实现时提交 JSON Schema 和对应测试。发布后的字段与含义保持兼容；破坏性调整提高 `schema_version`。比较命令与报告选项的契约统一见 [CLI 后续接口](cli.md#后续接口)。

## 协议与实现约束

DNS 报文构造与解析由项目自行实现，不能用现成 DNS 客户端库替代协议核心。响应须经过完整解析和事务匹配，UDP 还须验证来源；普通与加密传输均遵守同一查询总预算，证书验证失败不得回退明文。

名称与报文边界见[编解码约定](wire-codec.md)，传输细节见[网络约定](network.md)，职责与依赖见[架构](architecture.md)。输入规则集中在[输入校验](validation.md)，当前命令默认值和退出码集中在 [CLI](cli.md)。

## 不属于首版

- MX、NS、TXT、SOA、PTR 等直接查询类型；展示 CNAME 不表示支持直接查询 CNAME。
- 多轮采样、延迟百分位、排名、历史数据库和实时监控。
- DNSSEC 验证、IDN 自动转换、加密服务器比较、自动发现和代理配置。
- 自动递归追踪 CNAME、权威服务器发现或根服务器迭代查询。
- CSV、Markdown 报告和图形界面。

长期候选见[产品需求](prd.md)。
